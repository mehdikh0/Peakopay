درگاه پرداخت کارت به کارت Peakopay برای ووکامرس — تأیید خودکار سفارش با تطبیق تراکنش بانکی از طریق اپلیکیشن اندروید. ۱۰۰٪ رایگان و متن‌باز (GPL)؛ بدون نسخه پولی، بدون اشتراک، بدون سرویس اجباری.

== Description ==

Peakopay یک سامانه پرداخت کارت به کارت/انتقال بانکی است که به‌طور کامل روی زیرساخت خودتان اجرا می‌شود:

* **افزونه ووکامرس (همین افزونه)** — رایگان و متن‌باز، منتشرشده در مخزن رسمی وردپرس
* **سرور Peakopay** — رایگان و متن‌باز؛ روی هاست شخصی شما (cPanel/LiteSpeed و…) نصب می‌شود. بدون درخواست IP، بدون واسطه، بدون SaaS
* **اپ اندروید فروشنده** — رایگان؛ پیامک واریز بانکی را تشخیص می‌دهد و برای تطبیق به سرور شما می‌فرستد

هیچ سرویس پولی، اشتراک یا حساب Peakopay لازم نیست — همه اجزا در اختیار شماست.

= جریان پرداخت =

۱. مشتری در checkout روش «کارت به کارت (Peakopay)» را انتخاب و سفارش را ثبت می‌کند.
۲. افزونه از سرور Peakopay شما یک نشست پرداخت می‌سازد (با کلید تکرارناپذیری) و مشتری را به صفحه پرداخت می‌فرستد.
۳. صفحه پرداخت: شماره کارت مقصد (رمزنگاری‌شده در سرور، نمایش ماسک‌شده)، مبلغ دقیق و یکتا، شمارش معکوس.
۴. مشتری واریز می‌کند؛ اپ اندروید فروشنده پیامک بانکی را به سرور شما می‌فرستد.
۵. سرور تراکنش را تطبیق می‌دهد و وب‌هوک امضادار (HMAC-SHA256 + پنجره ±۳۰۰ ثانیه) به ووکامرس می‌فرستد.
۶. سفارش دقیقاً یک‌بار و به‌صورت خودکار تکمیل می‌شود.

= ویژگی‌ها =

* تطبیق خودکار واریز با سفارش (مبلغ، کارت مقصد، بازه زمانی)
* تأیید دستی پرداخت از پنل سرور (وقتی پیامک نرسیده باشد)
* صفحه پرداخت ریسپانسیو و فارسی/RTL با مهلت پرداخت و شمارش معکوس
* سازگار با Checkout بلوکی و Checkout کلاسیک ووکامرس
* سازگار با HPOS (جداول سفارش جدید ووکامرس)
* حالت تست کامل (پرداخت تستی + شبیه‌سازی پیامک) بدون دست‌زدن به سفارش‌های واقعی
* لاگ امن (بدون کلید محرمانه) در WooCommerce ← Status ← Logs
* آماده ترجمه (text domain: peakopay) — فارسی زبان اصلی است

= امنیت =

* تأیید سفارش فقط با وب‌هوک امضاشده — دکمه «پرداخت کردم» مشتری هرگز مبنای تأیید نیست (فقط یادداشت می‌گذارد).
* هر سفارش حداکثر یک‌بار تکمیل می‌شود (idempotent) و مبلغ وب‌هوک با مبلغ نشست تطبیق داده می‌شود.
* رویدادهای «تستی» هرگز سفارش واقعی را تکمیل نمی‌کنند.
* سفارش پرداخت‌شده هرگز به عقب تنزل داده نمی‌شود.
* بدون cURL مستقیم — همه درخواست‌ها از WordPress HTTP API؛ کلیدها فقط در تنظیمات ذخیره می‌شوند و هرگز در HTML/JS ظاهر نمی‌شوند.
* رشته‌ها escape، ورودی‌ها sanitize، دسترسی‌ها با nonce و capability محافظت می‌شوند.

= سازگاری =

* اگر ووکامرس فعال نباشد، افزونه فقط یک اعلان مدیریتی نشان می‌دهد و غیرفعال می‌ماند (هیچ fatal error ای نمی‌دهد).
* ووکامرس 6.0 تا 10.9، وردپرس 6.5 تا 7.1، PHP 7.4 تا 8.4.
* HPOS ✓ — Checkout Blocks ✓ — RTL ✓

== Installation ==

**پیش‌نیاز:** سرور Peakopay روی هاست شما نصب و راه‌اندازی شده باشد (بسته رایگان سرور + راهنمای نصب آن در پروژه Peakopay). بدون سرور، افزونه کار نمی‌کند.

۱. وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← `peakopay` (فایل zip) ← نصب ← فعال‌سازی.
۲. ووکامرس ← تنظیمات ← پرداخت‌ها ← «Peakopay (کارت به کارت)» ← فعال + مدیریت.
۳. مقادیر «آدرس سرور»، «شناسه فروشگاه (st_…)»، «کلید API (hpk_…)» و «کلید وب‌هوک (whsec_…)» را از مرحله ۶ نصب سرور Peakopay (یا تنظیمات ← اتصال ووکامرس) کپی کنید.
۴. آدرس وب‌هوک که باید در پنل سرور وارد کنید در همان صفحه نوشته شده است: `آدرس‌فروشگاه/wc-api/peakopay/`
۵. واحد مبالغ فروشگاه (تومان/ریال) و مهلت پاسخ سرور را تنظیم کنید.
۶. دکمه «تست اتصال به Peakopay» را بزنید (باید ✅ بدهد) و ذخیره کنید.
۷. در پنل سرور، کارت مقصد + شماره‌های فرستنده پیامک + قالب پیامک بانک خود را ثبت کنید و اپ اندروید را همراه‌سازی کنید.

= پرداخت اول را تست کنید =

۱. در پنل سرور Peakopay «حالت تست» را روشن کنید.
۲. پنل ← ابزارهای تست ← ساخت پرداخت تستی (حداقل ۲٬۰۰۰ تومان) + شبیه‌سازی پیامک بانکی.
۳. در ووکامرس یک سفارش واقعی ثبت کنید — رویداد تستی فقط یک یادداشت روی سفارش می‌گذارد و وضعیت آن را تغییر نمی‌دهد.
۴. برای تست کامل production: حالت تست را خاموش کنید و یک سفارش واقعی کوچک ثبت/واریز کنید.

== Frequently Asked Questions ==

= آیا برای استفاده باید هزینه‌ای بپردازم؟ =
نه. Peakopay به‌طور کامل رایگان و متن‌باز (GPL-2.0-or-later) است — افزونه، سرور و اپ اندروید. هیچ نسخه پولی، اشتراک یا قفل ویژگی وجود ندارد.

= آیا به سرویس اینترنتی Peakopay وصل می‌شود؟ =
نه — افزونه فقط به سروری وصل می‌شود که خودتان روی هاستتان نصب کرده‌اید و آدرسش را خودتان در تنظیمات وارد می‌کنید. هیچ درخواستی به هیچ سرور ثالث دیگری فرستاده نمی‌شود.

= سفارش مشتری تکمیل نشد؛ چه کنم؟ =
در پنل سرور Peakopay ← پرداخت‌ها ← وضعیت پرداخت و وضعیت وب‌هوک را ببینید؛ «ارسال مجدد وب‌هوک» را بزنید. اگر پیامک واریز اصلاً ثبت نشده، از بخش «در انتظار تأیید» اپ یا پنل می‌توانید پرداخت را دستی تأیید کنید. لاگ دیباگ افزونه (ووکامرس ← Status ← Logs، فایل peakopay-…) و لاگ رخدادهای پنل سرور برای عیب‌یابی کامل است.

= کلید API را گم کردیم =
از پنل سرور Peakopay ← تنظیمات ← اتصال ووکامرس، کلید جدید بسازید و در تنظیمات درگاه جایگزین کنید.

= افزونه ووکامرس را غیرفعال کرده‌ایم و سایت خطا می‌دهد؟ =
خیر — Peakopay در نبود ووکامرس فقط یک اعلان نشان می‌دهد و خودش غیرفعال می‌ماند. اگر خطایی می‌بینید از نسخه 1.0.2 یا بالاتر استفاده کنید.

= مبلغ سفارش با مبلغ صفحه پرداخت کمی فرق دارد؟ =
«مبلغ یونیک» است (حداکثر +۹۹۹ ریال برای یکتاسازی) و هنگام تطبیق خودکار لحاظ می‌شود؛ از پنل سرور قابل خاموش‌کردن است.

= بازپرداخت دارد؟ =
خیر — پرداخت کارت به کارت از سمت فروشنده باید دستی برگردد؛ افزونه/سرور فقط واریز را تطبیق می‌کند و سوابق را نگه می‌دارد.

== Privacy ==

برای هر پرداخت، افزونه اطلاعات حداقلی سفارش (شماره سفارش، مبلغ، نام و شماره تلفن صورتحساب) را به سرور خودمیزبان Peakopay همین فروشگاه ارسال می‌کند. سوابق پرداخت (شناسه نشست، مبلغ، بانک، کد رهگیری، وضعیت تأیید) روی سفارش ذخیره می‌شوند و بخشی از گزارش مالی شما هستند. هیچ داده‌ای به سرویس ثالث فرستاده نمی‌شود و ابزار «خروج داده شخصی» وردپرس این متاها را خروجی می‌دهد. متن پیشنهادی برای صفحه سیاست حریم خصوصی در تنظیمات ← حریم خصوصی وردپرس اضافه می‌شود.

== Security ==

تأیید پرداخت فقط از طریق وب‌هوک امضاشده (HMAC-SHA256 + پنجره زمانی ±۳۰۰ ثانیه + تطبیق مبلغ + تطبیق توکن نشست) انجام می‌شود. ادعای مشتری («پرداخت کردم») هرگز سفارش را تکمیل نمی‌کند. همه مسیرهای مدیریتی با nonce و capability محافظت شده‌اند. کلیدهای API هرگز در خروجی HTML/JS یا لاگ‌ها قرار نمی‌گیرند.

== Uninstall ==

حذف افزونه فقط تنظیمات درگاه را پاک می‌کند. متای پرداخت روی سفارش‌ها و سوابق مالی حفظ می‌شوند (نباید سوابق حسابداری با حذف افزونه نابود شوند).
