# پیکو پی — راهنمای نصب فارسی

این راهنمای ساده، نصب هر سه بخش پیکو پی را قدم‌به‌قدم توضیح می‌دهد: بک‌اند روی هاست، افزونهٔ ووکامرس و اپ اندروید. نسخهٔ انگلیسی: [`INSTALL.md`](../INSTALL.md).

---

## الف) نصب افزونهٔ ووکامرس

**پیش‌نیاز:** وردپرس ۶.۵+ با ووکامرس ۸+ نصب و فعال.

1. فایل `Peakopay-WooCommerce-v1.2.0.zip` را آماده کنید.
2. در مدیریت وردپرس: **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه**.
3. فایل ZIP را انتخاب کنید، **هم‌اکنون نصب کن** و بعد **فعال‌سازی**.
4. در ووکامرس به **پرداخت‌ها** بروید، درگاه **«پیکو پی — پرداخت کارت به کارت»** را فعال و روی **مدیریت** کلیک کنید.
5. **اتصال به سرور را پیکربندی کنید:**
   - **آدرس بک‌اند:** مثل `https://pay.example.com` (بدون / انتها)
   - **کلید فروشگاه:** از پنل مدیریت پیکو پی ← تنظیمات ← اتصال‌ها کپی کنید.
6. ذخیره کنید و دکمهٔ **تست اتصال** را بزنید — باید «موفق» بگوید.
7. قبل از رفتن روی حالت واقعی، یک سفارش تستی در **حالت تست** بزنید و کل جریان را بررسی کنید.

نیاز به هیچ پیکربندی دیگری نیست؛ وب‌هوک‌ها خودکار و امضادار ارسال می‌شوند.

## ب) نصب بک‌اند روی هاست (cPanel)

**پیش‌نیازها:**

- PHP **8.1 یا جدیدتر** با افزونه‌های `pdo_mysql`، `mbstring`، `curl` و `sodium` یا `openssl` (یکی از دومی کافی است).
- دیتابیس **MySQL 8+ / MariaDB 10.6+**.
- **HTTPS** روی دامنه (برای پرداخت عملاً ضروری است).
- **بدون نیاز به** SSH، Composer، Node.js یا Cron.

**مراحل:**

1. **آپلود:** در cPanel ← File Manager، فایل `Peakopay-Backend-v2.2.0.zip` را در پوشهٔ مقصد (مثلاً `public_html/pay/`) آپلود و همان‌جا استخراج کنید. در پوشه باید مستقیماً `index.php`، پوشهٔ `app/` و `migrations/` باشد.
2. **ساخت دیتابیس:** cPanel ← **MySQL Databases**: یک دیتابیس (مثلاً `cpaneluser_peakopay`) و یک کاربر اختصاصی بسازید و همهٔ دسترسی‌های آن دیتابیس را به کاربر بدهید. سه چیز را یادداشت کنید: نام دیتابیس، نام کاربری، رمز.
3. **نصب‌کنندهٔ وب:** آدرس `https://دامنه-you/pay/install` را در مرورگر باز کنید. نصب‌کنندهٔ ۷ گامی:
   1. بررسی پیش‌نیازها (نسخهٔ PHP + افزونه‌ها، قابل‌نوشتن بودن `storage/`)
   2. دیتابیس — همان نام/کاربر/رمز مرحلهٔ ۲
   3. حساب مدیر — ایمیل و رمز قوی
   4. فروشگاه — نام و مشخصات
   5. کارت مقصد — کارتی که مشتریان به آن واریز می‌کنند
   6. اتصال‌ها — اتصال فروشگاه ووکامرس (کلید فروشگاه)
   7. پایان
   فایل `config/config.php` ساخته، مهاجرت‌ها به‌صورت خودکار اعمال و نصب‌کننده قفل می‌شود.
4. **امنیت (توصیه‌شده):**
   - سایت حتماً با HTTPS سرو شود.
   - `debug` خاموش بماند (پیش‌فرض نصب‌کننده درست است).
   - پوشه‌های `storage/` و `config/` با فایل‌های `.htaccess` همراه پروژه روی هاست‌های Apache/LiteSpeed محافظت شده‌اند.
5. **کرن نگهداری (اختیاری — برای تأیید پرداخت لازم نیست؛ تطبیق همان لحظه انجام می‌شود):** cPanel ← Cron Jobs، هر ۱۵ دقیقه:
   ```
   php -q /home/USERNAME/public_html/pay/cron.php
   ```
   اگر هاست کرن ندارد، نگهداری با HTTP و توکنِ تنظیمات ← سیستم هم ممکن است (شرح در `CPANEL.md`).
6. **بررسی نهایی:** به `https://دامنه-you/pay/admin` بروید و با حساب مدیر وارد شوید؛ داشبورد باید بالا بیاید. در تنظیمات ← سیستم، ابزار عیب‌یابی داخلی هم هست.

## ج) نصب اپ اندروید

1. **دریافت APK:** فایل `Peakopay-Android-v2.3.1.apk` (نسخهٔ release) را روی گوشی نصب کنید؛ اگر پرسید اجازهٔ «نصب از این منبع» بدهید. حداقل **اندروید ۸** لازم است.
2. **اتصال حساب — دو راه:**
   - **کد همراه‌سازی (کلاسیک):** پنل مدیریت ← دستگاه‌ها ← افزودن دستگاه؛ کد کوتاه (مثل `K7M2Q9`) را در اپ وارد کنید. دستگاه «در انتظار تأیید» ظاهر می‌شود — در پنل تأییدش کنید.
   - **ورود با حساب (ساده‌تر):** در اپ «ورود با حساب» را بزنید و ایمیل/رمز پنل را وارد کنید؛ دستگاه بلافاصله فعال و همهٔ فروشگاه‌های حسابتان دیده می‌شوند.
3. **مجوزها:** اپ مجوز **پیامک** (برای خواندن پیامک واریز بانکی) و **اعلان** می‌خواهد. پیامک فقط روی گوشی خودِ فروشنده خوانده می‌شود و فقط پیامک‌هایی که قواعد واریز بانکیِ تعریف‌شده در سرور را مطابقت دهند پردازش می‌شوند — پیامک شخصی، تبلیغاتی، برداشت و خرید هرگز ارسال نمی‌شود. فهرست کامل مجوزها و دلیلشان: `ANDROID-PERMISSIONS.md`.
4. **همگام‌سازی اولیه:** پس از اتصال، اپ قواعد پیامک و فروشگاه‌ها/کارت‌ها و داشبورد را می‌گیرد. اگر اینترنت قطع بود، پیامک‌های بانکی در صف اپ می‌مانند و با بازگشت اتصال خودکار ارسال می‌شوند — چیزی گم نمی‌شود.
5. **سرویس همیشه‌روشن (اختیاری، پیش‌فرض روشن):** با یک اعلان کم‌صدا وضعیت اتصال را زنده نگه می‌دارد؛ از صفحهٔ «وضعیت» اپ قابل خاموش‌کردن است.

## د) راه‌اندازی توسعه

1. سورس را clone یا دانلود کنید.
2. **بک‌اند و تست‌ها** — PHP 8.1+ (CLI) با `pdo_mysql`، `mbstring`، `curl` + یک MySQL/MariaDB محلی:
   ```bash
   mysql -u root -e "CREATE DATABASE peakopay_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
                     CREATE DATABASE peakopay_e2e CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
                     CREATE USER 'hp'@'localhost' IDENTIFIED BY 'hp_test_pass';
                     GRANT ALL ON peakopay_test.* TO 'hp'@'localhost';
                     GRANT ALL ON peakopay_e2e.* TO 'hp'@'localhost';"

   php tests/run.php   # کل مجموعه: ۷۴۵ بررسی (unit + سناریوهای افزونه + e2e کامل HTTP)
   ```
   دیتابیس‌های تست پیش‌فرض `peakopay_test` و `peakopay_e2e` هستند (با متغیرهای `HP_TEST_DB`، `HP_TEST_DB_USER`، `HP_TEST_DB_PASS` قابل تغییر).
3. **اپ اندروید:** پوشهٔ `android/` را در Android Studio باز کنید (یا `./gradlew assembleDebug`). JDK 17+ و platform 35 لازم است. امضای release فایل‌های `keystore.properties` و keystore می‌خواهد که در مخزن عمومی **نیستند** — توضیح در `android/README.md`.
4. **افزونهٔ ووکامرس:** سورس در `woocommerce/peakopay/` است و رفتارش با همان مجموعهٔ تست و استاب‌های وردپرس پوشش داده شده (`tests/plugin-scenarios/`).
