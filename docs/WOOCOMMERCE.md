# اتصال ووکامرس — پیکو پی

راهنمای کامل نصب افزونه و راه‌اندازی درگاه کارت به کارت. حدود ۱۰ دقیقه.

---

## پیش‌نیازها

- وردپرس ۵.۸+ و ووکامرس ۵.۵+
- سرور پیکو پی نصب‌شده (راهنما: `docs/CPANEL.md`) و مقادیر گام ۶ نصب:
  - آدرس سرور (مثلاً `https://pay.example.com`)
  - شناسه فروشگاه `st_…`
  - کلید API `hpk_…`
  - کلید وب‌هوک `whsec_…`
- فروشگاه ووکامرس روی **HTTPS**

## نصب افزونه

1. پوشه `woocommerce/peakopay` را به‌صورت zip کنید (یا از بسته، فایل `peakopay-woocommerce.zip` را بردارید).
2. وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل zip را نصب و **فعال** کنید.

## تنظیم درگاه

1. ووکامرس ← تنظیمات ← پرداخت‌ها (Checkout).
2. در لیست روش‌ها، **«پیکو پی (کارت به کارت)»** را فعال کنید و روی «مدیریت» کلیک کنید.
3. مقادیر را پر کنید:

   | فیلد | مقدار |
   |---|---|
   | آدرس سرور پیکو پی | `https://pay.example.com` (بدون / انتها) |
   | شناسه فروشگاه | `st_…` |
   | کلید API فروشگاه | `hpk_…` |
   | کلید امضای وب‌هوک | `whsec_…` |
   | واحد مبالغ فروشگاه | تومان (IRT) اگر قیمت‌های ووکامرس به تومان است؛ ریال (IRR) اگر به ریال |

4. دکمه **«تست اتصال به پیکو پی»** را بزنید — باید ✅ و نام فروشگاه را نشان دهد.
5. ذخیره کنید و درگاه را فعال بگذارید.

## تست وب‌هوک (مهم)

پیکو پی برای تأیید سفارش‌ها به آدرس `https://YOURSTORE.com/wc-api/peakopay` وب‌هوک می‌فرستد.

1. در پنل مدیریت پیکو پی: **تنظیمات ← اتصال ووکامرس ← تست اتصال** — نتیجه را ببینید. اگر خطا داد:
   - آدرس فروشگاه (بدون / انتها و با https) را در پنل چک کنید؛
   - افزونه امنیتی (Wordfence و مانند آن) نباید `wc-api` را مسدود کند؛
   - HTTPS فروشگاه فعال باشد.

## جریان پرداخت مشتری

1. مشتری در checkout روش «کارت به کارت (پیکو پی)» را انتخاب و سفارش را ثبت می‌کند.
2. به صفحه پرداخت پیکو پی می‌رود: شماره کارت مقصد (ماسک‌شده + دکمه کپی)، **مبلغ دقیق و یونیک** (برای جلوگیری از اشتباه واریز، تا ۹۹۹ ریال به مبلغ اضافه می‌شود که در سایت شما «مبلغ نمایشی» حساب می‌شود و هنگام تطبیق خودکار لحاظ می‌شود)، شمارش معکوس، و کد پیگیری.
3. مشتری از بانک خود کارت به کارت می‌کند.
4. اپ اندروید فروشنده پیامک واریز را دریافت می‌کند ← سرور تطبیق می‌دهد ← وب‌هوک امضادار به ووکامرس ← **سفارش خودکار «در حال انجام/تکمیل‌شده» می‌شود** و مشتری روی صفحه پرداخت «پرداخت شد ✅» و دکمه بازگشت به فروشگاه را می‌بیند.

> دکمه «پرداخت کردم» روی صفحه پرداخت **هرگز** سفارش را تأیید نمی‌کند — فقط یک یادداشت اطلاعاتی روی سفارش می‌گذارد. تنها وب‌هوک معتبرِ سرور، سفارش را تکمیل می‌کند.

## حالت تست (بدون پول واقعی)

1. در پنل پیکو پی: **تنظیمات ← عمومی ← حالت تست** را روشن کنید.
2. از پنل: **ابزارهای تست ← ساخت پرداخت تستی** (حداقل ۲٬۰۰۰ تومان — برابر حداقل مبلغ پرداخت).
3. در همان صفحه، «شبیه‌سازی پیامک بانکی» را با مبلغ همان پرداخت تستی اجرا کنید.
4. پرداخت تستی «تستی» برچسب می‌خورد، در گزارش‌ها جدا دیده می‌شود و **سفارش واقعی ووکامرس را هرگز تکمیل نمی‌کند** (فقط یادداشت).

برای تست کاملِ اتصال ووکامرس، می‌توانید در تنظیمات درگاه در ووکامرس فعلاً یک درگاه دوم واقعی را همزمان فعال نگه دارید.

## سؤالات رایج

**سفارش پرداخت‌شده در ووکامرس «در انتظار» ماند.**
پنل پیکو پی ← پرداخت‌ها ← جزئیات پرداخت ← وضعیت وب‌هوک را ببینید؛ «ارسال مجدد وب‌هوک» را بزنید. اگر باز خطا داد `docs/TROUBLESHOOTING.md` را ببینید.

**کلید API را گم کردیم.**
پنل پیکو پی ← تنظیمات ← اتصال ووکامرس ← «ساخت کلید جدید»، بعد در تنظیمات درگاه جایگزین کنید.

**مبلغ سفارش با مبلغ صفحه پرداخت کمی فرق دارد.**
طبیعی است: «مبلغ یونیک» برای یکتاسازی واریز است (حداکثر +۹۹۹ ریال) و هنگام تطبیق به‌صورت خودکار لحاظ می‌شود. برای خاموش‌کردن این رفتار، در پنل ← تنظیمات ← پرداخت ← «مبلغ یونیک» را خاموش کنید (توصیه: روشن بماند).

**HPOS (جداول سفارش جدید ووکامرس)؟**
افزونه به‌طور رسمی سازگار است؛ نیازی به تغییر نیست.


## دکمه «تست اتصال» (افزونه ۱.۰.۲+)

با کلیک، افزونه با مقادیر فرم (ذخیره‌نشده هم قابل تست است) به سرور وصل می‌شود و نتیجه چندخطی برمی‌گرداند:

- ✅ اتصال برقرار است — فروشگاه، نسخه سرور
- واحد پول فروشگاه (تومان/ریال)
- تعداد کارت‌های فعال و فرستنده‌های پیامک ثبت‌شده
- تعداد دستگاه‌های اندروید فعال
- ⚠ هشدار اگر سرور در حالت تست باشد

اگر خطا داد: پیام سرور علت را می‌گوید (اعتبارنامه نامعتبر، آدرس اشتباه، …). نتیجه هر تست در پنل پیکو پی ← «وضعیت اتصال‌ها» ← «آخرین تست اتصال افزونه» هم ثبت می‌شود.

نکته فنی: افزونه اعتبارنامه‌ها را هم در هدر و هم در بدنه می‌فرستد تا هاست‌هایی که هدر Authorization را حذف می‌کنند مشکل ایجاد نکنند.

## دور ۱۷ — نسخه ۱.۱.۰ (آماده‌سازی انتشار در مخزن رسمی وردپرس)

این نسخه افزونه را برای انتشار در **WordPress.org Plugin Directory** آماده می‌کند:

- **Checkout بلوکی:** درگاه حالا در checkout بلوکی ووکامرس (پیش‌فرض نسخه‌های جدید) هم دیده می‌شود — `includes/class-peakopay-blocks.php` + `assets/js/peakopay-blocks.js` (بدون build step). مسیر تأیید همان مسیر سرور است (بدون هیچ پردازش داده در JS).
- **اعلان سازگاری:** `custom_order_tables` (HPOS) و `cart_checkout_blocks` هر دو declare شدند.
- **بین‌المللی‌سازی:** همه رشته‌ها با text domain `peakopay` قابل‌ترجمه + `languages/peakopay.pot` (۸۴ رشته).
- **حریم خصوصی:** متن پیشنهادی سیاست حریم خصوصی + exporter متای پرداخت برای ابزار «خروج داده شخصی» وردپرس.
- **لایسنس:** `LICENSE.txt` (متن کامل GPL-2.0) در بسته افزونه.
- **متادیتا:** حذف Plugin URI ساختگی، `Requires Plugins: woocommerce`، سازگاری وردپرس 6.5–7.1 / ووکامرس 6.0–10.9.
- **برند:** نام کلاس‌ها و همه پیام‌ها به «Peakopay» یکدست شد (هدرهای قدیمی `X-HamrahPay-*` وب‌هوک فقط برای سازگاری سرورهای نصب‌شده قبلی حفظ شدند).
- **uninstall:** فقط تنظیمات حذف می‌شود؛ متای پرداخت سفارش‌ها (سوابق مالی) باقی می‌ماند — تست خودکار دارد.

نصب مثل قبل؛ اگر از قبل نصب کرده‌اید، فقط zip جدید را جایگزین کنید — شناسه درگاه (`peakopay`) و کلید تنظیمات (`woocommerce_peakopay_settings`) تغییر نکرده و هیچ مهاجرتی لازم نیست.

## فروشگاه دوم (چندفروشگاهی — پنل ۲.۰.۰+)

هر فروشگاه (سایت ووکامرس) به‌صورت مستقل به Peakopay وصل می‌شود و تراکنش‌ها/کارت‌ها/تنظیماتش کاملاً جدا نگه داشته می‌شوند:

۱) در پنل Peakopay از بخش **«فروشگاه‌ها»** (بعد از افزودن فروشگاه دوم در منو ظاهر می‌شود؛ یا تنظیمات ← فروشگاه‌ها و اعضای تیم) یک فروشگاه جدید بسازید.
۲) **شناسه فروشگاه (st_…)**، **کلید API (hpk_…)** و **کلید امضای وب‌هوک (whsec_…)** فروشگاه جدید را از همان صفحه کپی کنید — کلید API فقط همان یک‌بار نمایش داده می‌شود.
۳) افزونه Peakopay را روی سایت دوم نصب کنید و در تنظیماتش **همان آدرس سرور** + شناسه و کلیدهای *فروشگاه دوم* را وارد کنید.

همین بخش تاشو داخل صفحهٔ تنظیمات درگاه (ووکامرس ← تنظیمات ← پرداخت‌ها ← Peakopay) هم هست. توجه: کلیدهای هر فروشگاه فقط در سایت همان فروشگاه کار می‌کنند — داده‌ها ایزوله‌اند. «تست اتصال» نام فروشگاهِ متصل را نشان می‌دهد تا مطمئن شوید کلید درست را زده‌اید.
